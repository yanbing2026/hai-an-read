共约 9,400 字。后续章节与整本电子书的发布方式待定。

## 怎么生成的

`novel-site-build.py` 读手稿目录里的 `chapter0N.md`，按章渲染成阅读优先的 HTML：

- 章节标题取自每个文件自己的 `#` 标题，目录不会和手稿脱节
- 正文按段落切分，`---` 渲染成分场符，`>` 渲染成引用块
- 文本在渲染前统一做 HTML 转义
- 中文长文排版：衬线字体、1.95 行距、首行缩进 2em、最大宽度 36rem

重新生成：

```sh
novel-site-build.py --chapters 1,2,3 [--author 笔名]
git add -A && git commit -m "..." && git push
```

`src/` 下另存一份原始 markdown，便于脱离生成器恢复文本。
